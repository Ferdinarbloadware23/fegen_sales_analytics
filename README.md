# Fegen Sales Analytics Pipeline

## Project Overview

This project focuses on analyzing sales data from Fegen.id, an e-commerce business operating on the Shopee marketplace. It follows the typical workflow of a data analytics project, starting from raw operational data, followed by data preparation, database design, SQL analysis, and business reporting.

The primary objective is to transform transactional data into structured information that supports operational monitoring and business decision-making.

---

## Business Objectives

The analysis is designed to answer several operational and business-related questions, including:

- What is the total sales revenue?
- Which products generate the highest revenue?
- How do monthly sales perform over time?
- Which products require inventory replenishment?
- Who are the repeat customers?
- How much does each product contribute to overall revenue?

## Project Workflow

The project follows the workflow below:

1. Raw data extraction from Shopee Seller Center
2. Data cleaning and preparation using Microsoft Excel
3. Data import into a MySQL relational database
4. SQL-based data analysis
5. Business reporting and dashboard development
6. Business insight generation
